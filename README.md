# Rift Shop Resource Pack

Resource pack for Sanctuary Rift Shop (Minecraft Paper 26.2+).

- **Seraph Plume** (Elytra skin)
- **Folded Wings** (Back accessory)
- **Ember Moth** (Elytra skin)
- **Starmotes** (Aura accessory)

Merged with the production **Return by Death** v1 sound & visual assets (`assets/returnbydeath`).
